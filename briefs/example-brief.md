# Brief: team reading-list app design

A book club needs a simple shared reading-list web app. The three of you will produce a one-page design proposal (features, data model, tech stack). Do not build anything; the deliverable is the agreed proposal text in the transcript.

## Definition of Done
1. The transcript contains an agreed one-paragraph vision statement.
2. The transcript lists at least 5 concrete features.
3. The transcript names a concrete tech stack with a one-line rationale each.
4. The proposal fits on one page.
5. The solution must be feasable for free. Cost: 0$
